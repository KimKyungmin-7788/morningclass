# 포트폴리오 후속 협의

2026-10-24 사용자 요청: 같은 학생이 같은 교육 웹앱에서 수행한 결과를 날짜별뿐 아니라 활동별로 묶어 변화를 확인한다. 교과별 결과를 모아 종합의견을 작성하는 기능도 추가한다.

## 현재 구현 범위

학생 카드의 포트폴리오는 가상 자료를 쓰는 화면 시안이다. 활동별 변화, 비교에서 제외한 조건, 근거 기록 이동, 교과별 요약, 고정 종합의견 예시 불러오기·수정·검토 완료 체험만 제공한다. 실제 서버 수신, 자동 분석, AI 호출, 저장은 하지 않는다.

## 실제 생성 기능 구현 전에 사용자에게 반드시 요청할 것

사용자는 종합의견 생성 지침과 프롬프트를 나중에 함께 고도화하기를 명시했다. 실제 생성 기능을 연결하기 전 이 문서를 확인하고 사용자에게 아래 사항의 공동 검토를 요청한다. 예시 초안을 확정된 교육 평가 지침으로 사용하지 않는다.

- 용도: 교사 참고, 학부모 공유, 공식 기록 중 어디까지인가?
- 기간·분량·문체, 강점과 지원 필요 사항을 서술하는 방식
- 포함할 교과와 교사 관찰, 사용 가능한 근거·금지할 추정
- 기록 부족·상반된 결과·도움 조건 변화의 처리
- 출처 표시와 교사 검토·수정·확정 절차
- 실제 사례로 프롬프트를 함께 검토하고 승인할 기준

## 데이터 설계 시 지킬 구분

학생 ID + 앱 ID + 활동 ID로 묶는다. 같은 앱이라도 다른 학습 목표나 활동은 합산하지 않는다. 난이도·문항 수·측정 방식·도움 조건·지표 버전이 비교 가능한 경우에만 변화 수치를 제시한다. 조건이 다른 기록은 삭제하지 않고 별도 표시한다. 교과가 다른 점수를 총점으로 합산하지 않는다. 시간 단축을 무조건 향상으로 해석하지 않는다. 원본과 분석 결과를 분리하고, 의견에는 사용한 기록의 ID와 생성 지침 버전을 남긴다.
