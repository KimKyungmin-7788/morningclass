# 학생 카드 기획 (누가기록 · 개별화교육계획)

작성 2026-10-22. 이 문서대로 단계별로 만든다. 모양은 `DESIGN.md`, 폴더 구조와 규칙은 `docs/v2/01-구조.md` 를 따른다.

## 1. 목표

매일 아침 루틴과 수업 중 관찰이 그대로 **학생별 기록**과 **개별화교육계획(IEP)의 근거**로 쌓이게 한다. 따로 시간을 내어 정리하지 않아도, 기록은 클릭 두 번으로 남는다.

## 2. 정해진 것

| 항목 | 결정 |
| --- | --- |
| 들어가는 곳 | 상단 줄 가운데 빈자리에 **학생 이름 칩** |
| 카드 구조 | **앞면**(학생과 함께 봐도 됨) / **뒷면**(선생님 기록, PIN 잠금) |
| 잠금 | 4자리 **PIN**. **쓰기는 PIN 없이**, 지난 기록을 **볼 때만** PIN |
| PIN을 잊었을 때 | 이 기기에서 만든 **백업 파일을 고르면** 새 PIN을 정할 수 있다 (자료는 바꾸지 않음) |
| IEP | **과목 → 학기 목표 → 월 목표**. 월 목표마다 해당 달을 체크박스로 여러 개 고른다 |
| 월말 평가 | 따로 표시하지 않는다. **기록만** 목표 아래에 모인다 |
| 누가기록 | **수시로**. 학생 → 빠른 문장 두 번 누르면 저장, 같은 창에서 세부 입력 |
| 도움 수준 | 넣는다: 혼자 / 말로 도움 / 보여 주기 / 손잡고 (고르지 않아도 됨) |
| 도전행동 | 분류에 넣고, 고르면 **ABC 기록**(선행사건·행동·결과)과 강도·지속 시간 칸이 열린다 |
| 학부모 공유 | 앞면 + **"학부모와 나누기"를 체크한 누가기록**만 상담 자료로 인쇄 |
| 저장 위치 | 지금처럼 **이 기기(IndexedDB)에만**. 서버로 보내지 않는다 |

## 3. 화면

### 3-1. 상단 줄의 이름 칩

```
[아침교실] 햇살초 · 꿈반  [2026. 10. 22. 목요일]   (가온✓)(나래)(다온✓)(라온)(마루) [✎ 기록]   [🔊][📁][⚙️]
```

- 날짜 카드와 오른쪽 단추 사이(`src/app/Header.tsx` 의 `<DateCard />` 와 `.actions` 사이)에 둔다.
- 칩 = 학생 이름. 그날 아침 활동(출석·감정)을 마친 학생은 ✓.
- 학생이 9명 이상이거나 칸이 모자라면 칩 대신 **"학생 카드"** 단추 하나 → 누르면 이름 목록.
- **✎ 기록** 단추는 늘 보인다(수업교실·판서 중에도). 누르면 3-3 빠른 기록 창.
- 보관된 학생(`archived`)은 칩에 나오지 않는다.

### 3-2. 학생 카드 (창, `Popup large`)

**앞면 · 나의 하루** (잠금 없음)
- 오늘: 출석 상태, 오늘 감정, 맡은 역할과 '했어요' 여부, 오늘 받은 칭찬 스티커
- 이번 주: 감정 분포(8종 막대), 칭찬 스티커 수와 이유, 역할 수행 일수
- 이번 달: 출석·지각·조퇴·결석 수
- 생활표현 연습 수준(문장·낱말·그림 카드) — kv `expr:<학급>` 의 `levels[학생]`

**뒷면 · 선생님 기록** (PIN)
- 탭: `누가기록` · `개별화교육계획` · `학생 정보`
- 누가기록: 최신순 목록, 분류·월 목표·학부모 공유로 거르기, 눌러서 고치기·지우기
- 개별화교육계획: 3-4
- 학생 정보: 출결 사유 목록, 알레르기
- 뒷면은 **창을 닫거나 3분 동안 손대지 않으면 다시 잠긴다.**
- 창 아래: **📄 상담 자료 인쇄** (3단계)

### 3-3. 빠른 기록 창 — "누르면 저장, 고치면 바로 반영"

```
┌ ✎ 기록 ─────────────────────────────────────────────┐
│ 누구?   [가온✓] [나래] [다온✓] [라온] [마루] …          │  여러 명 선택 가능
│                                                      │
│ 빠른 기록 (누르면 바로 저장)                            │
│ [스스로 했어요] [도움 받아 했어요] [친구를 도왔어요]       │
│ [집중이 어려웠어요] [기분이 좋아 보였어요] [⚠ 도전행동]    │
│ [＋ 내 문장]                                           │
├──────────────────────────────────────────────────────┤
│ ✓ 가온·다온 저장됨 · 10:42                 [되돌리기]   │
│ 내용   스스로 했어요 | (이어서 쓰면 자동 저장)            │
│ 분류   (학습) 행동  도전행동  건강  교우관계  가정 연계    │
│ 목표   [국어 · 교실 물건 이름 읽기 ▾]  ← 이번 달 목표만   │
│ 도움   혼자  (말로 도움)  보여 주기  손잡고              │
│ 공유   ☐ 학부모와 나누기                               │
└──────────────────────────────────────────────────────┘
```

흐름
1. 학생 칩을 고른다(학생 카드에서 열었다면 그 학생이 골라져 있다).
2. **빠른 문장을 누르는 순간 저장**된다. 고른 학생마다 기록이 하나씩 생긴다.
3. 저장 직후 아래 세부 칸이 방금 기록으로 채워진다. 고치면 **바로 저장**(입력이 멈추고 0.5초 뒤). 저장 단추는 없다.
4. 빠른 문장 없이 내용 칸에 바로 써도 같다(첫 글자를 쓰는 순간 기록이 생긴다).
5. **되돌리기**는 방금 만든 기록을 지운다(10초 동안 보임).
6. 여러 명에게 저장한 뒤 세부 칸을 고치면 **모두에게** 반영된다. 한 명만 고치려면 학생 카드에서 고친다.

세부 규칙
- **분류·목표는 앞 기록을 기억**한다(같은 창을 열어 둔 동안). 다시 열면 비운다.
- 내용 칸 위의 빠른 문장은 내용 앞에 붙는다. 내용은 자유롭게 고칠 수 있다.
- 빠른 문장은 설정에서 더하고 지우고 순서를 바꾼다. 기본 6개는 위 그림대로.
- **⚠ 도전행동**을 누르면 분류가 `도전행동`이 되고 ABC 칸이 열린다.

  | 칸 | 입력 |
  | --- | --- |
  | 선행사건(A) | 짧은 글 + 자주 쓰는 보기 칩(과제 제시 · 활동 전환 · 요구 거절 · 기다리기 · 소음) |
  | 행동(B) | 짧은 글 |
  | 결과·대응(C) | 짧은 글 + 보기 칩(휴식 제공 · 과제 조정 · 무시하기 · 대체 행동 안내 · 자리 이동) |
  | 강도 | 약 / 중 / 강 |
  | 지속 시간 | 분 (숫자, 비워도 됨) |

- **쓰는 내용이 전자칠판에 비친다.** 창을 닫으면 내용이 화면에서 바로 사라지고, 빠른 기록 창에는 **지난 기록 목록을 보여 주지 않는다**(방금 만든 것만).

### 3-4. 개별화교육계획

```
학기 [2026-1 ▾]   과목 [＋ 과목]

국어
 └ 학기 목표  생활 속 낱말을 읽고 뜻을 안다                       [✎][🗑]
     ├ 월 목표  교실 물건 이름 10개 읽기    ☑3 ☑4 ☐5 ☐6 ☐7 ☐8   기록 6
     └ 월 목표  그림 보고 알맞은 낱말 고르기  ☐3 ☐4 ☑5 ☑6 ☐7 ☐8  기록 2
     [＋ 월 목표]
 [＋ 학기 목표]
```

- 학기 = `YYYY-1`(3~8월) · `YYYY-2`(9~다음 해 2월). 학기에 따라 체크할 수 있는 달이 바뀐다.
- 과목은 학급의 과목 목록(`subjects`)에서 고르거나 직접 쓴다.
- **이번 달 목표**: 지금 달이 체크된 월 목표. 뒷면 첫 화면 위쪽과 빠른 기록의 목표 고르기에 나온다.
- 월 목표를 누르면 그 목표에 연결된 누가기록이 날짜순으로 보이고, **도움 수준 변화**가 작은 줄그래프로 보인다(2단계).
- 학년이 바뀌어도 지난 학기는 남는다(학기 고르기로 본다).

### 3-5. PIN

- 처음 뒷면을 열 때 PIN 4자리를 두 번 입력해 정한다.
- 숫자판은 화면 숫자 단추(전자칠판에서 키보드 없이). 누른 숫자는 ●로만 보인다.
- 5번 틀리면 1분 기다린다.
- 설정 → **학생 기록** 탭: PIN 바꾸기, **PIN을 잊었어요**, 빠른 문장 관리, 도전행동 보기 칩 관리.
- **PIN을 잊었어요**: 백업 파일을 고른다 → 파일 안의 `recoveryKey` 가 이 기기의 것과 같으면 새 PIN을 정한다. **자료는 불러오지 않는다**(지금 자료 그대로).
  - `recoveryKey` 는 PIN을 처음 정할 때 만든 무작위 값(32바이트, hex). kv 에 두고 백업 파일에 함께 넣는다.
  - 백업이 없으면 되찾을 수 없다고 미리 알린다. PIN을 처음 정한 직후 **"지금 백업 받기"**를 권한다.
- PIN은 화면 잠금이다. 저장소의 자료를 암호화하지 않는다(개인정보처리방침에 그대로 적는다).

### 3-6. 상담 자료 인쇄 (3단계)

- 기간(이번 달 / 이번 학기 / 직접)을 고른다.
- 내용: 앞면 요약(출결·감정 분포·칭찬·역할) + **학부모와 나누기를 체크한 누가기록**.
- 도전행동 기록은 공유를 체크해도 인쇄 전에 한 번 더 확인한다.
- 인쇄 / PDF 저장은 학습지 PDF와 같은 방식으로.

## 4. 자료 형식

`src/core/data/types.ts` 에 더한다. `SCHEMA_VERSION` 1 → 2.

```ts
export type NoteCategory = 'study' | 'behavior' | 'challenge' | 'health' | 'peer' | 'home';
export type SupportLevel = 'independent' | 'verbal' | 'model' | 'physical';   // 혼자 · 말로 도움 · 보여 주기 · 손잡고
export type Semester = string;                                                // 'YYYY-1' | 'YYYY-2'

/** 누가기록 한 건 */
export interface StudentNote {
  id: string;
  classId: ClassId;
  studentId: StudentId;
  /** 기록한 때 (ISO). 날짜를 고치면 이 값을 바꾼다 */
  at: string;
  text: string;
  category?: NoteCategory;
  /** 연결한 월 목표 */
  goalId?: string;
  support?: SupportLevel;
  /** 도전행동일 때만 */
  abc?: { a: string; b: string; c: string; intensity?: 'low' | 'mid' | 'high'; minutes?: number };
  share?: true;
  /** 여러 학생에게 한 번에 남긴 기록끼리 같은 값 (함께 고치기용) */
  batch?: string;
  updatedAt: string;
}

/** 개별화교육계획: 학급 · 학생 · 학기마다 하나 */
export interface Iep {
  id: string;
  classId: ClassId;
  studentId: StudentId;
  semester: Semester;
  subjects: IepSubject[];
}
export interface IepSubject { id: string; name: string; goals: IepSemesterGoal[] }
export interface IepSemesterGoal { id: string; text: string; monthly: IepMonthlyGoal[] }
/** months: 1~12 (그 학기에 속한 달만) */
export interface IepMonthlyGoal { id: string; text: string; months: number[] }

/** 학생 기록 설정 (kv 'studentNotesConfig') */
export interface NotesConfig {
  quick: string[];          // 빠른 문장
  abcA: string[];           // 선행사건 보기
  abcC: string[];           // 결과·대응 보기
}
```

`AppData` 에 더한다: `studentNotes: StudentNote[]`, `ieps: Iep[]`, `notesConfig: NotesConfig`, `recoveryKey?: string`.
**PIN 자체(`pinHash`)는 백업에 넣지 않는다.**

### 저장소 (`src/core/storage/db.ts`)

- `DB_VERSION` 1 → 2. `onupgradeneeded` 에서 새 store 둘:
  - `notes` (keyPath `id`, index `byStudent` = `['classId', 'studentId']`)
  - `ieps` (keyPath `id`, index `byStudent` = `['classId', 'studentId']`)
- kv 열쇠: `studentNotesConfig`, `recoveryKey`, `pinHash`(`{ salt, hash, iter }`, PBKDF2-SHA256 · 100,000회, WebCrypto).
- `readAll` / `replaceAll` / `deleteClassData` 에 두 store 를 넣는다. 학급을 지우면 그 학급의 기록·IEP도 지운다.
- `replaceAll` 은 `pinHash` 를 지우지 않는다(백업을 불러와도 지금 PIN 유지). 단, 불러온 백업의 `recoveryKey` 가 다르면 PIN을 지우고 다음에 새로 정하게 한다.
- 예전 백업(schemaVersion 1)을 불러오면 새 칸은 빈 값으로 채운다(`parseBackup`).
- **함께 고칠 것**: 지금 `readAll` / `replaceAll` 은 정해진 kv 열쇠만 옮겨서, 생활표현 설정(kv `expr:<학급>` — 학생별 연습 수준·이번 주 상황)이 **백업에 빠져 있다.** v2 로 올리면서 `AppData.expr: Record<ClassId, ExprBook>` 으로 넣고, 새로 kv 에 두는 값도 반드시 백업에 들어가는지 시험으로 확인한다.

### 학생 이동 · 삭제

- 학생을 명단에서 빼면(보관) 기록은 남는다. 학생 카드 목록에는 안 나오고, 설정의 보관된 학생에서 열 수 있다.
- 학생을 완전히 지울 때는 "누가기록 N건과 개별화교육계획도 함께 지워져요"를 확인한다.

## 6. 개인정보 · 보안

- **민감정보**(장애·건강·행동)다. 서버·외부로 보내지 않는다. 새 외부 주소가 없으니 CSP는 바꿀 필요 없다.
- `privacy.html` 1장 목록에 더한다: 누가기록(내용·분류·도움 수준·도전행동 ABC·학부모 공유 표시), 개별화교육계획(과목·학기 목표·월 목표), PIN의 해시와 복구 열쇠.
- PIN은 **화면 잠금**이고 자료를 암호화하지 않는다는 것, 백업 파일에는 이 기록이 **그대로 들어간다**는 것을 적는다.

## 앞면·빠른 기록 화면 개선 (2026-10-23)

- 앞면은 선택한 날짜의 출석·감정·역할·칭찬을 네 칸으로 요약한다. 학생 이동 단추와 나의 하루/선생님 기록 전환을 분리한다.
- 이번 주 감정은 기록된 항목만 표시하고, 없으면 한 줄 안내로 대체한다. 칭찬·역할은 작은 요약으로, 칭찬 이유는 펼쳐 보는 목록으로 둔다.
- 월 출결은 숫자를 구분해서 보여 주고 생활표현은 수준 배지로 표시한다.
- 빠른 기록은 학생 선택 → 빠른 문장 → 세부 입력 순서를 유지하며 넓은 화면에서는 선택과 입력을 나란히 둔다. 문장 누르기·자동 저장·되돌리기의 기존 동작은 유지한다.
- 도전행동 입력 이름을 직전 상황(A)·보인 행동(B)·이후 대응(C)으로 쉽게 표시한다. 저장 형식은 바꾸지 않는다.

상단 이름은 배경·테두리 없는 보조색 글자 단추로 표시해 아침 활동을 방해하지 않도록 한다. 이름의 터치 영역은 64px 이상 유지하고, 마우스를 올리거나 키보드로 초점을 맞출 때만 배경을 표시한다.
