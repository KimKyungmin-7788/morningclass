# 오늘은 어떤 옷? — 동작 시안 2단계

2026-10-23. 사용자 요청: 남학생·여학생을 구분해 단계적으로 개발하고, 분리된 기본 아바타와 티셔츠·재킷으로 실제 겹쳐 입기를 확인한다.

## 범위

- `/outfit-preview.html` 독립 진입점. 기존 앱 카드로 등록하지 않는다.
- 남학생·여학생 아바타 각 1개. 옷은 성별 제한 없이 공용이다.
- 기본 옷(크림 티셔츠·반바지·양말)을 입은 아바타 위에 산호색 티셔츠와 열린 민트 재킷을 순서대로 쌓는다.
- 누르기와 포인터 끌기(마우스·터치·펜)로 입히고, 옷 목록 또는 입은 옷 단추로 벗긴다. 같은 옷을 드롭하면 벗겨지지 않는다.
- 재킷을 벗겨도 티셔츠는 남는다. 아바타별 옷차림은 창을 열어 둔 동안 따로 기억한다. 되돌리기는 현재 아바타의 최근 20번 착용 변경까지 지원한다.
- 계절별 옷장 필터와 상의·하의·겉옷·신발 분류를 제공한다. 날씨에 맞는 아이템은 먼저 표시하고, 모든 계절 보기로 자유롭게 조합한다. 필터 변경은 입힌 옷을 바꾸지 않는다. 적절성 평가와 실제 날씨 연계는 후속 단계다.
- 브라우저 저장소에 접근하지 않는다. 새로고침하면 초기화된다. 사용자 학급 자료와 무관하다.

## 에셋

`public/img/outfit/`의 `boy.png`, `girl.png`, `shirt.png`, `jacket.png`는 분리된 RGBA PNG. 같은 1024×1536 캔버스를 사용한다. 그림의 저작 원본은 Codex generated_images에 보존한다. 정적인 첫 UI 시안의 그림은 실제 레이어로 사용하지 않았다.

남학생 기본 아바타를 기준으로 여학생·옷을 참조 생성했다. 여학생의 몸 자세·기본 의상은 같은 규격이다. 머리 모양과 얼굴이 다르다. 이미지는 imagegen으로 제작했고 투명도와 실제 합성을 확인한다. 생성 후보를 사용자 최종 승인본으로 간주하지 않는다.

- `model.test.ts`: 겹쳐 입기, 겉옷 벗기기, 안쪽 옷 변경, 아바타별 상태 보존

## 다음 단계

현재 정면 자세와 레이어 정합을 검토한 뒤 비옷 등 아이템을 확장한다. 학생별 영구 저장·백업과 날씨 피드백은 본 앱 통합 때 별도 기획한다.

## 시안 확인 결과

- 재킷은 어깨 위치를 수정한 `jacket-v2.png`를 사용한다. 첫 후보 `jacket.png`는 비교용으로 보존한다. CSS에서 공통 몸체 기준점에 맞춰 배치하며, 열린 중앙은 실제 알파 0인 영역으로 안쪽 티셔츠가 보인다.
- 네 기본 에셋의 실제 크기 1024×1536, RGBA 확인.
- 미리보기에서 남·여 선택, 클릭 입히기, 마우스 드래그로 티셔츠→재킷 입히기, 겉옷만 벗기기, 되돌리기를 확인했다.
- 학생 자료를 읽거나 바꾸지 않았다. 실제 터치 기기·펜은 아직 직접 시험하지 않았다.

## 2단계 추가 (2026-10-23)

- 긴바지·운동화·장화·스웨터·패딩 PNG 5개 추가. 기본 티셔츠·반바지 포함 총 9개를 선택한다.
- 각 부위는 하나만 착용한다. 상의/하의를 벗기면 기본 티셔츠/반바지로 돌아간다. 신발 교체는 바지나 겉옷에 영향을 주지 않는다.
- 남학생·여학생 공용 의상, 아바타별 착용 상태 분리. 아바타 전환 시 되돌리기 이력은 비운다.
- 원본 그림은 보존하고 CSS로 허리·발·어깨 위치를 맞췄다. 장화 착용 시 바지 밑단은 장화 안에 들어가게 표시한다.
- 브라우저에서 남·여 착용, 긴바지·신발 교체, 계절 필터 유지, 패딩 겹쳐 입기를 확인했다. 실제 터치 기기는 미시험이다.
- 모델 시험 6개: 부위별 교체, 레이어 순서, 아바타 독립, 계절/날씨 필터, 필터 변경 시 옷 보존. 앱 데이터·백업 형식에는 변경이 없다.

## 아침교실 연결 (2026-10-23)

- `features/outfit/manifest.tsx`에서 ‘오늘은 어떤 옷?’ 카드를 등록했다. 기본 배치에 넣지 않고 하단 바구니에 둔다. 기존 칸과 배치는 바꾸지 않으며 사용자가 배치 편집으로 옮길 수 있다.
- 학생을 고른 다음 아바타와 옷을 선택한다. ‘다 입었어요’에서만 저장하며, 완료 전 선택은 초안이다. 선택 날짜·학급·학생 ID별로 구분한다.
- 학생 카드 ‘나의 하루’에 선택 날짜의 옷차림을 표시한다. 메인 카드는 그 날짜에 마지막으로 완료한 재학 학생 한 명만 표시한다. 보관된 학생은 메인 후보에서 제외한다.
- 저장 형식 v3: DayRecord에 선택 필드 outfits(학생 ID → avatar, clothes, season, weather, completedAt), lastOutfitStudentId를 추가했다. IndexedDB v3으로 올릴 때 기존 레코드를 덮어쓰지 않는다. v1·v2 백업에서 없는 필드는 미완료로 읽는다.
- 완료 자료는 하루 기록과 함께 백업·복원·학급 삭제에 포함된다. 개인정보처리방침에 저장 항목을 추가했고 그림 경로의 CSP와 같은 출처 리소스 정책을 명시했다. 새 외부 전송은 없다.
- `core/data/outfits.ts`는 저장 완료를 기다린 후 화면을 갱신한다. 저장 실패 시 창을 닫지 않고 다시 누를 수 있다. 공통 `core/ui/OutfitFigure.tsx`로 메인·학생 카드가 같은 그림을 그린다.
- 옷 아이템의 보조 설명을 없애고 이름만 표시한다. 옷입히기 창 첫 문장과 학생 선택으로 안내하며 별도 Tour는 추가하지 않는다.
- 자동 시험: 학생별·날짜별·학급별 저장 보존, 마지막 완료 교체, 백업 왕복, v2 저장소→v3와 v2 백업 호환, 새 칸 배치 보존을 추가했다.

### 창 크기 조정

학생은 펼침 선택 메뉴로 고른다. 옷입히기 창은 화면 높이에 맞추고 아바타·완료 버튼을 계속 표시한다. 옷장은 6개씩 이전/다음으로 넘기며 창 전체 스크롤을 없앴다. 학생 선택, 옷 착용과 페이지 전환을 브라우저에서 확인했다. 이 화면 확인에서는 완료 저장을 누르지 않았다.

## 학생별 아바타와 조작 (2026-10-23)
학생 이름 버튼을 상단에 표시하고 선택 전 편집기를 흐리게 비활성화한다. 학생별 첫 아바타 선택은 Student.outfitAvatar에 저장하며 schema/DB v4에서 누락은 미선택으로 해석한다. 백업의 학급 자료에 포함한다. 옷을 누르거나 옷 그림을 아바타로 끌어 입히고, 입은 옷을 옷장으로 끌거나 키보드로 해당 부위 단추를 눌러 벗긴다. 기본 티셔츠·반바지는 벗기지 않는다. 제작 기준은 `옷입히기-에셋-제작규칙.md`를 따른다.

## 봄 옷장 확장 (2026-10-24)
- 신발과 기타를 분리했다. 기타의 모자(hat)와 스카프(neck)는 함께 착용한다.
- 줄무늬 티셔츠, 분홍 카디건, 베이지 면바지, 초록 모자, 물방울 스카프를 추가했다. 봄 12종, 전체 14종이다.
- 3열 세로 스크롤을 적용했다. 카드 간격은 24px, 좁은 화면은 18px이다. 여백은 touch-action:pan-y로 스크롤하고 카드 자체는 드래그한다.
- schema/DB v5. 기존 hat, neck 누락은 미착용으로 처리하며 백업에 포함한다.

## 여름·가을·겨울 확장 (2026-10-24)
계절별 3종씩 총 9종을 추가해 전체 옷장은 23종이다. 여름 10종, 가을 15종, 겨울 10종이 해당 필터에서 보인다. 단풍 맨투맨·카고바지는 겨울에도 사용할 수 있다. 계절을 바꿔도 이미 입힌 옷은 유지된다.
저장 버전은 v6이며 기존 옷차림은 변경하지 않는다. 새 ID의 IndexedDB 전체 백업 왕복과 v5→v6 호환을 시험했다.
