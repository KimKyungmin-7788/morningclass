# 옷입히기 에셋 제작·검수 규칙


## 현재 필수 기준: 몸 기준점과 착용 합성 (2026-10-24 수정)

**이 절이 아래의 과거 외곽 경계 보정 기록보다 우선한다.** 그림 외곽의 너비·높이가 같아도 소매·손목·발목은 맞지 않는다. 옷 착용에는 외곽 경계 정규화를 사용하지 않는다. `outfitRegistration.json`은 옷장 썸네일·드래그 그림과 기존 소품 배치 용도로 남긴다.

### 고정 몸

기준 원본은 `public/img/outfit/storybook/boy.png`, 여학생은 `girl-v2.png`다. 두 그림은 같은 몸 자세와 좌표를 사용하며 머리 모양만 다르다. 기존 PNG와 옷 디자인은 보존한다. 착용 화면의 공통 좌표계는 **1024 × 1536**, 좌상단 (0,0)이다. 머리 크기에 맞춰 몸 전체를 재정규화하지 않는다.

| 기준 | 왼쪽 / 중심 | 오른쪽 |
| --- | --- | --- |
| 목 중심 | (512, 550) | — |
| 어깨 | (390, 575) | (634, 575) |
| 손목 중심 | (265, 875) | (759, 875) |
| 허리 중심 | (512, 890) | — |
| 발목 중심 | (395, 1360) | (629, 1360) |
| 신발 바닥 높이 | y = 1500 | y = 1500 |

좌우는 화면 기준이다. 소매는 손목 단면의 기울기에 맞추며, 몸통보다 소매 끝이 위에 있는 원본은 각각 별도 대응점을 둔다. 어깨와 몸통에는 옷 두께에 따른 여유를 둘 수 있지만 손목·발목 연결은 움직이지 않는다. 이 숫자와 구현 기준은 `src/core/ui/outfitRig.ts`에 관리한다.

### 기존 디자인을 보존하는 합성

- 원본 옷의 색·무늬·주머니·단추·소매 시보리를 유지한 채, 원본 기준점과 몸 기준점을 삼각형 단위로 대응시켜 화면에 그린다. 파일을 다시 그리거나 PNG 픽셀을 덮어쓰지 않는다.
- 상의는 목·어깨·겨드랑이·밑단, 긴소매는 **아이템마다 측정한 소매 끝**을 추가로 맞춘다. 좌우 소매와 몸통을 하나의 확대율로 억지로 맞추지 않는다.
- 하의는 허리·가랑이·바짓단으로 구간을 나눈다. 운동화는 왼발·오른발을 따로 맞추고 바지 뒤에 그린다.
- 장화는 바지 앞에 그린다. 긴바지는 무릎 아래만 장화 입구 안쪽으로 좁히고, 장화 안에 들어간 부분은 가린다. 반바지는 이 보정을 적용하지 않는다.
- 기본 아바타에 포함된 티셔츠·반바지·양말은 새 옷을 입는 부위에서만 가린다. 긴소매 아래 기존 팔 윤곽, 겉옷 밖 안쪽 티셔츠 소매가 중복해서 보이면 실패다. 손은 남겨 소매와 이어지게 한다.
- 닫힌 패딩·코트는 안쪽 상의를 가린다. 열린 재킷·카디건은 중앙의 안쪽 상의를 유지한다.
- 메인 카드·학생 카드·편집 창·검수 화면은 모두 `OutfitFigure.tsx` 하나를 사용한다. 별도 화면에 옷 위치 CSS를 복사하지 않는다.

### 새 옷을 만들 때

1. 위 몸 기준 원본과 유지할 디자인 이미지를 함께 참조한다. 동일한 1024×1536 캔버스·정면 자세·손목 기울기·허리·발목 간격을 명시한다.
2. 생성 결과를 외곽 크기만으로 통과시키지 않는다. 실제 소매 끝·바짓단·신발 입구의 원본 좌표를 기록한다.
3. `outfitRig.ts`에 해당 옷의 대응점을 추가한다. 생성물이 기준점과 크게 다르면 재제작하며, 그림 전체를 늘려 다른 부위를 희생하지 않는다.
4. 남녀 모두 단독 착용 → 상의+겉옷 → 하의+운동화 → 하의+장화 순서로 확대 검수한다. 같은 몸을 쓰므로 성별마다 별도 보정값을 만들지 않는다.
5. 마지막에는 실제 카드 크기로 줄여 보고, 클릭·드래그로 입기/벗기기·되돌리기도 확인한다.

### 통과 기준과 이번 확인

- 소매와 손목 사이 배경색 틈, 겉옷 밖의 이중 팔/기본 소매, 바지 밖 기본 반바지, 신발 밖 기본 발 윤곽이 없어야 한다.
- 바짓단은 신발 입구와 겹치고, 장화는 양쪽 입구 안으로 바지가 들어가야 한다.
- `docs/옷입히기-화풍-검수.html`에서 남녀 28개 상태(기본·단품·계절별 조합)를 나란히 볼 수 있다. 이전/다음은 확대 보기, 전체 보기는 비교용이다.
- 이번 수정은 모든 단품의 남녀 합성과 봄·여름·가을·겨울·비 오는 날 조합을 화면에서 확인했다. 실제 편집 창에서는 클릭 착용·재킷 드래그 벗기기를 확인했다. 실제 터치 기기는 별도로 시험하지 않았다.
- `outfitRig.test.ts`는 모든 조각의 기준점 대응, 뒤집힘 방지, 이웃 경계 연속성, 장화 착용 시 무릎 위 보존을 시험한다. 이 자동 시험은 시각 검수를 대신하지 않는다.

## 감정 그림과 통일하는 화풍 기준 (2026-10-24)

이 절은 이후 제작에 적용하는 최신 미술 기준이다. 아래의 예전 제작 기록과 좌표는 원본 계보·정렬 참고로 보존한다.

### 참조 이미지의 관찰

고정 화풍 참조는 `public/img/emotion/person.webp`, `girl.png`와 두 캐릭터의 감정별 8장이다. 기존 옷입히기 개체는 형태·색·기능 참조로 사용한다. 감정 그림의 옷이나 소품을 옷입히기 목록에 새로 끼워 넣지 않는다.

| 요소 | 감정 그림에서 관찰한 표현 | 옷입히기에 적용할 기준 |
|---|---|---|
| 실루엣·비율 | 큰 둥근 머리, 작은 몸통, 짧고 둥근 손발. 머리 높이가 전신의 약 2/5인 유아 그림책 비율 | 둥근 형태와 단순화를 적용한다. 이번 교체에서는 레이어 호환 때문에 기존 몸 비율·관절 좌표는 유지한다. 새 비율을 도입하려면 몸과 모든 옷을 한꺼번에 재등록해야 한다 |

### 감정을 표현하는 문법과 적용 범위

감정 그림은 얼굴 → 몸짓 → 배의 감정 친구 → 주변 기호가 같은 의미를 반복한다.
- 기쁨: 웃는 곡선 눈, 열린 입, 활짝 펼친 팔, 노란 친구와 햇살.
- 슬픔: 처진 눈썹·닫힌 눈·눈물, 축 처진 팔, 파란 친구와 빗방울.
- 화남: 안쪽으로 기운 눈썹, 벌린 입·주먹, 빨간 친구와 증기·진동선.
- 피곤: 감긴 눈·하품·눈 비비기, 보라 친구와 Z 표시.
- 신남: 꽉 감긴 눈·큰 웃음·올린 팔과 한쪽 다리, 주황 친구와 방사선.
- 불안: 올라간 안쪽 눈썹·불안한 입·모은 손, 파란 친구와 땀·떨림.
- 그냥: 타원 눈·짧은 입·편안한 자세, 담담한 노란 친구.
- 아픔: 찡그린 눈·몸 기울임·배 감싸기, 보라 친구와 반창고·아픔 표시.

옷입히기에는 화풍만 가져온다. 감정 친구·배의 점선 원·눈물·진동선·Z·증기는 넣지 않는다. 의상의 계절·날씨 기능을 감정 색으로 바꾸지 않는다.

### 소재별 단순화

- 면/청: 큰 색면과 주머니·밑단 정도. 촘촘한 직조나 입체 봉제 제거.
- 니트: 굵은 꽈배기·골지의 리듬은 유지하되 실 한 올까지 묘사하지 않는다.
- 패딩: 둥근 가로 구획과 최소한의 접힘. 광택 대신 옅은 색 번짐.
- 코트: 남색 바탕과 나무 토글·주머니 형태 유지. 금속/가죽 광택 제거.
- 밀짚: 큰 엮임 무늬와 청록 리본 유지. 가느다란 짚의 전수 묘사 제거.
- 신발·장화·우산: 기존 색·한 쌍/한 개·손잡이 방향 유지. 둥근 외곽선과 넓은 하이라이트만 허용.

### 버전과 제작 프롬프트

기존 `public/img/outfit/*.png`는 보존한다. 새 화풍은 `public/img/outfit/storybook/`에 같은 파일명으로 별도 저장한다. ID·이름·계절·슬롯·저장 형식은 변경하지 않는다. 아바타, 실제 레이어, 옷장 썸네일, 드래그 그림 모두 같은 경로 함수를 사용한다.

아바타 프롬프트: “참조 1의 기존 몸 실루엣·1024×1536 캔버스·목/어깨/허리/손목/발 위치·자세·크림 티셔츠·남색 반바지·흰 양말을 유지한다. 참조 2 감정 캐릭터의 갈색 타원 눈, 짧은 입, 둥근 홍조, 부드러운 갈색 외곽선, 넓은 수채화 색면으로 화풍만 바꾼다. 얼굴의 사실적 디테일과 반사광은 없앤다. 배의 점선과 감정 친구는 복사하지 않는다. 투명 배경.”

옷 프롬프트: “참조 1의 기존 개체만 화풍을 바꾼다. 캔버스, 개체 경계·위치·목선·소매 끝·밑단·색·문양·주머니·단추·열린 앞 중심을 유지한다. 참조 2의 따뜻한 그림책 수채화 외곽선과 큰 안료 색면으로 단순화한다. 실사 직조·봉제·광택·과도한 주름을 줄인다. 개체를 확대하거나 중앙 재배치하지 않는다. 인체·배경·후광·그림자는 제외하고 열린 부분은 투명하게 둔다.”

### 전환 검수

1. 아이템 누락이나 다른 옷으로의 교체가 없는지 전체 목록과 대조한다.
2. 얼굴의 눈·입·볼과 옷의 외곽선·질감을 같은 화면에서 비교한다.
3. 양쪽 몸의 목/손목/허리/발을 기준으로 레이어를 맞춘다. 생성 도구의 좌표 준수는 보장되지 않으므로 브라우저 합성으로 검수한다.
4. 닫힌 겉옷의 기본 반팔 가림, 열린 겉옷의 속상의 노출, 긴바지/장화, 모자/머리, 우산/손 위치를 확인한다.
5. 기존 학생의 저장된 ID를 바꾸지 않고 새 그림을 표시하는지 확인한다. 실사용 데이터는 수정하지 않고 독립 미리보기에서 검수한다.


기준 그림: `public/img/outfit/boy.png`, `girl.png`. 원본은 덮어쓰지 않는다.
목적은 캐릭터를 새로 그리는 것이 아니라 같은 자세의 몸에 독립된 옷 레이어를 올리는 것이다.

## 좌표와 레이어

- 캔버스 1024 × 1536, 투명 PNG. 원점은 좌상단. 자르거나 콘텐츠에 맞춰 자동 확대하지 않는다.
- 목 중심 약 (512, 510), 어깨 약 (370, 550) / (654, 550), 손목 약 (270, 840) / (754, 840), 허리 약 (512, 850). 수치는 시작점이며 양쪽 기준 그림과 실제 합성으로 확정한다.
- 옷은 몸 자세에 맞춰 팔이 아래·바깥으로 뻗는 형태. 소매 끝의 중심과 각도를 손목에 맞춘다. 손은 옷 이미지에 그리지 않는다.
- 기본 몸 → 하의 → 상의 → 겉옷 → 신발 순. 열린 재킷의 앞 중심은 투명해 안의 티셔츠가 보여야 한다.
- 정렬은 `src/core/ui/outfitFigure.css`만 수정한다. 편집기·메인 카드·학생 카드 모두 `OutfitFigure`를 쓴다. 화면마다 별도 보정 금지.

## 승인 전 필수 확인

1. 실제 알파 채널과 모서리 투명도를 확인한다. 격자무늬가 그려진 배경은 탈락이다.
2. 남·여 기본 몸 위에 각각 합성한다. 목선, 양쪽 어깨, 손목, 허리, 밑단을 확대해서 확인한다.
3. 긴 소매 끝이 손과 분리되거나 팔이 소매 바깥으로 튀어나오지 않아야 한다. 기본 티셔츠 어깨가 바깥으로 새어 나오면 폭만 늘리지 말고 팔 각도와 소매를 다시 맞춘다.
4. 티셔츠+재킷, 스웨터+패딩, 바지+장화 조합을 확인한다. 속옷 레이어가 겉옷 밖으로 불필요하게 튀어나오는지 확인한다.
5. 작은 메인 카드와 큰 편집기 양쪽에서 확인한다. 옷장 썸네일과 드래그 그림도 옷 전체가 보이고 다른 신체 부위가 포함되지 않아야 한다.
6. 입히기·벗기기·되돌리기 후 레이어가 복구되는지 확인한 다음 승인한다. 프롬프트만으로 정렬을 보장하지 않는다.
