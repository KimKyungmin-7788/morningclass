# 오늘의 생활표현 · 상황 그림 목록

상황 그림은 파일 이름만 맞춰 `public/img/expression/` 폴더에 넣으면 저절로 나온다.
그림이 없는 상황은 지금처럼 이모지가 대신 나온다. 그림을 일부만 넣어도 된다.

## 파일 규칙

- 폴더: `public/img/expression/`
- 이름: 아래 표의 **파일 이름** + `.webp` (없으면 `.png` 도 읽는다)
- 크기: 가로 4 : 세로 3, 1600 × 1200px 정도
- 용량: 한 장에 300KB 이하가 좋다. png 로 만들었으면 webp 로 바꾸면 훨씬 가볍다.
- 그림 안에 글자는 넣지 않는다. 상황 문장은 화면이 그림 아래에 따로 보여 주고 읽어 준다.

## 그림 그릴 때

- **곤란한 순간**을 그린다. 혼자 해 봤는데 안 되는 장면이다.
  - 예: 뚜껑을 두 손으로 돌리며 찡그린 얼굴
- 도움을 청할 **상대가 보이게** 그린다.
  - 선생님께 청하는 상황: 뒤쪽에 선생님
  - 친구에게 청하는 상황: 옆에 친구
- 같은 주제 안에서는 **같은 아이 캐릭터**를 쓴다. 상황만 바뀌고 주인공은 같아야 아이들이 "또 그 친구"로 알아본다.
- 배경은 단순하게, 교실·급식실처럼 우리 학교 장면으로 그린다.

## 새 주제를 더할 때

1. 그림 파일 이름은 `주제-번호-낱말` 꼴로 짓는다.
   - 예: `thanks-1-pencil`, `sorry-2-bump`
2. 그림과 함께 상황마다 아래 내용을 알려 주면 `src/features/expression/data.ts` 에 넣는다.
   - 상황 문장
   - 문장 수준의 말 · 낱말 수준의 말
   - 그림 카드의 말과 다른 보기 카드
   - 이어서 할 말 (예: 도와주면 → 고맙습니다.)
3. 주제는 한 주에 하나씩 차례로 돌아간다. 2026-10-12 주가 1주차이고, 마지막 주제 다음에는 1주차로 돌아간다.
