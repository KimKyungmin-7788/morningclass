# 아침교실 v2 — 구조와 규칙

React + TypeScript + Vite + Zustand. 시험은 Vitest.

## 실행

```bash
npm install
npm run dev      # http://localhost:3000/app.html (기존 앱은 /legacy.html)
npm run check    # 타입 검사 + 시험
npm run build    # dist/ 로 빌드
```

## 폴더

```
index.html  privacy.html     소개 · 개인정보처리방침 (그대로)
app.html                     새 앱 진입점
public/legacy.html           기존 앱(main 배포본) — 옮기는 동안 나란히 비교, 전환 뒤 삭제
public/img/                  그림 파일
api/                         Vercel 서버 함수 (neis, image) — 그대로
src/
├─ main.tsx
├─ app/                      화면 뼈대: App, Header, Dashboard, Footer, SideSwitch
├─ core/                     여러 기능이 함께 쓰는 것
│   ├─ prefs.ts              이 기기의 보기 설정 (소리 끄기, 마지막 교실)
│   ├─ data/                 저장 형식(types) · 기존 자료 변환(migrateLegacy) · 백업 · 학급 저장소(store)
│   │                        하루 기록(day) · 낱개 자료 훅(kv) · 공휴일(holidays)
│   ├─ storage/db.ts         저장 창구(IndexedDB) — 기능은 직접 쓰지 않고 core/data 를 거친다
│   ├─ sound.ts  tts.ts      효과음 · 음성 안내
│   └─ ui/                   Popup, toast, CardFrame
├─ features/                 기능 하나 = 폴더 하나
│   ├─ types.ts  registry.ts 카드 등록 구조 (manifest 자동 수집)
│   ├─ date/ weather/ dday/ notes/ video/ tools/   옮긴 기능 (model.ts = 계산, manifest.tsx = 카드)
│   └─ placeholders/         아직 안 옮긴 카드의 자리 표시 — 옮길 때마다 한 줄씩 뺀다
└─ styles/legacy.css         기존 스타일 전체 — 기능을 옮기며 기능 폴더로 나눈다
docs/v2/                     점검표 · 구조 문서
```

## 규칙

1. **기능은 폴더 하나.** `src/features/<이름>/manifest.ts(x)` 가 카드를 등록하면 대시보드에 자동으로 붙는다. `registry.ts` 는 고치지 않는다.
2. **계산과 화면을 나눈다.** 집계·파싱·쪽 나누기 같은 계산은 React 를 모르는 `.ts` 파일에 두고 `*.test.ts` 로 시험한다. 화면(`.tsx`)은 그 결과를 그리기만 한다.
3. **기능끼리 직접 부르지 않는다.** 다른 기능의 값이 필요하면 `core` 의 저장소(store)를 구독한다.
4. **저장은 `core/storage` 한 곳으로.** 기능이 `localStorage`·IndexedDB 를 직접 건드리지 않는다. 기존 `mc_` 자료는 읽기만 한다(지우지 않음).
5. **학생은 고유 번호(id)로 참조한다.** 이름을 키로 쓰지 않는다.
6. **모양은 기존과 같게.** 기존 클래스 이름을 그대로 쓰면 `legacy.css` 가 적용된다. 옮긴 기능의 스타일은 그 기능 폴더의 CSS 로 떼어 낸다.
7. **기존 앱(`main`)은 버그 수정만.** 수정이 생기면 `v2` 에 병합하고, 이미 옮긴 기능이면 새 코드에도 반영한다.
8. **단계가 끝나면** `npm run check` → 화면 확인 → 점검표 갱신 → `v2` 에 커밋·푸시.
