## 아직 사람이 확인해야 하는 것

- 실제 교실에서 쓰던 백업 파일을 새 버전에서 불러와 건수·내용 대조 (감정·급식·그림이 들어 있는 자료)
- 인쇄와 PDF 저장을 실제로 눌러 출력물 확인 (학습지 3종, 출결 대시보드 인쇄·엑셀)
- 전자칠판에서 손으로 끌기(시간표·감정·날짜 스티커), 소리·음성 안내
- 운영 주소에서 학교 검색·급식 불러오기·그림 자동 넣기·GPS 날씨

## 교체 순서

1. `main` 에서 최신 운영본 확인 → `v2` 에 병합할 변경이 있는지 본다 (동결 이후 `main` 변경: 자동 삭제 중단 1건 — 이미 병합됨)
2. `v2` 를 `main` 에 병합하고 푸시 → Vercel 이 운영 주소(morningclass.vercel.app)에 배포
3. 배포 뒤 확인: `scripts/check_live.sh https://morningclass.vercel.app` (헤더 5종, /privacy · /terms · /og.png, og 메타)
4. 운영 주소에서 `/app` 을 열어 기존 자료가 자동으로 옮겨지는지 확인 ("기존 자료를 옮겼어요" 알림, 학급·기록 건수)
5. 학교 검색 · 급식 불러오기 · 그림 찾기 · 학습지 PDF 를 한 번씩 실행
6. 설정 → 백업에서 파일로 저장해 둔다 (교체 직후의 기준점)

## 되돌리기

- 기존 앱의 자료(`mc_` 로 시작하는 localStorage 값)는 새 버전이 읽기만 하고 지우지 않는다.
  단, 설정의 "자료 모두 지우기"를 누르면 기존 자료도 함께 지워진다.
- 문제가 생기면 Vercel 에서 교체 전 배포로 되돌린다(Instant Rollback) → 교체 시점의 기록이 그대로 보인다.
- **한계**: 교체 뒤 새 버전에서 입력한 내용은 기존 앱에 보이지 않는다. 되돌리기 전에 새 버전에서 백업 파일을 받아 두면, 다시 새 버전으로 올 때 불러올 수 있다.
- 기존 앱은 교체 뒤에도 `/legacy` 주소로 열린다(자료는 교체 시점 그대로). 안정화되면 `public/legacy.html` 을 지운다.
