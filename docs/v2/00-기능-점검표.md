# 아침교실 v2 이전 — 0단계: 기능 점검표

기준: `main` 커밋 `0e4ea2c` (2026-10-10 배포본)의 `app.html` 6,324줄.
용도: 새 틀(React + TypeScript + Vite + Zustand)로 옮길 때 빠뜨리는 기능이 없도록 대조하는 목록.
각 항목 끝의 `함수명`은 기존 `app.html`에서 찾을 위치다. 옮긴 뒤 `[ ]`를 `[x]`로 바꾼다.

## 3. 대시보드와 작은 카드 (3단계)

> 3단계 완료(2026-10-10). (완료 축하 연출은 7단계에서, 기능 제안·첫 접속 흐름은 5단계에서 마침)

- [x] 대시보드 4열 배치 + 카드 등록 구조(이후 숨기기·순서 바꾸기의 토대) ★
- [x] **내 맘대로 배치**(예전 이름: 화면 꾸미기 · 사용자화): 상단의 '내 맘대로 배치' 단추나 카드를 길게 누르고 곱셈 문제를 맞히면(또는 설정의 '지금 배치하기') 자리 바꾸기·빼기·넣기(보관함), 학급별 저장, 빈 칸은 흐린 점선. 카드는 칸 크기(아주 작은·작은·보통·큰)에 맞춰 모습이 바뀌고, 아침 준비 진행률은 놓인 카드만 센다 ★
- [x] **1인 1역할**(새 카드, 보관함에서 시작): 역할 넣기(자주 쓰는 역할·직접 만들기)·그림 고르기·맡을 학생 고르기(여럿 가능)·한 칸씩 돌리기, 학생이 이름표를 눌러 '오늘 했어요', 결석 학생은 제외, 날짜별 기록(이전 기록 보기에 표시) ★
- [x] **칭찬판**(새 카드, 보관함에서 시작): 학생마다 자기 판(포도·나무·별, 10·20·30칸), 선생님만 스티커 주기(곱셈 확인, 5분 동안 유지), 칭찬 이유 3개까지·보상 후보 4개까지, 다 채우면 보상 고르고 새 판, 방금 준 것 취소(빼앗기는 없음), 1인 1역할 '했어요'에 자동으로 주기(선택), 날짜별 기록, 학생별 맞춤(한 학생에게만 더해 주는 칭찬 이유·보상 각 2개까지 — 설정의 '학생별 맞춤' 쪽 또는 칭찬판의 '맞춤 정하기'), 보통 칸은 5명부터 두 열, 보상을 고르면 칭찬 인증서(이름·칭찬받은 일·보상·날짜·학급)를 창으로 보여 주고 인쇄·이미지 저장(인증서 자체는 저장하지 않음) ★
- [x] **판서 카드**(보관함에서 시작): 수업 도구 카드 안의 단추였던 판서를 따로 카드로 뺌. 하단 줄의 바구니 목록에서 이름을 눌러도 열린다 ★
- [x] **날짜**: 날짜 고르기 달력, 공휴일 표시(고정·음력표·선거일·대체공휴일 계산), 주말 "쉬는 날", 학급별 "오늘 날짜 입력" 잠금 화면 `loadDate` `renderDatePicker` `holidaysOfYear` `checkDateGate`
- [x] **날씨**: 고르기, 움직이는 날씨 장면, 기온·체감 표현, GPS로 정답 확인(○/✕), 날씨별 한마디·준비물 `openWeather` `chooseWeather` `checkWeather` `WX_THEME`
- [x] **미세먼지**: 고르기, GPS로 PM10 자동 조회 `openDust` `autoDust` — 지금은 날씨 창에서 날씨와 함께 고르거나 GPS 확인 때 함께 불러온다(카드의 미세먼지 단추·따로 뜨는 창은 없앰, 카드에는 결과만 표시)
- [x] 위치 조회: 약 1km로 흐린 좌표만 Open-Meteo에 전송 `getPosition` `geoWeather` `geoDust`
- [x] **D-DAY**: 추가·삭제·정렬, 날짜와 무관하게 항상 표시 `openDday` `ddaySorted`
- [x] **유의사항**: 입력 — 임시 저장(draft)은 없앰: 저장을 눌러야 반영, 손글씨 표시, 임시 저장 `openNotes`
- [x] **영상 재생**: 기본 영상, 떠 있는 재생 창, 재생 이력, 제목 자동 가져오기(YouTube oEmbed), 쿠키 없는 재생 `openVideoPlayer` `recordVideo`
- [x] **수업 도구**: 시계(바늘+숫자)·타이머(원형, 1~30분, ±1분, 끝나면 소리·음성)·스톱워치, 학급별로 쓸 도구 고르기, 창을 닫아도 타이머 유지 ★ `renderTools` `openTool` `toolTick`
