# 마음 일기 여자아이 캐릭터 (2026-10-24)

## 기준과 생성

기존 person.webp 및 person-<감정>.webp 8장을 직접 확인했다. 기존 자세·감정 친구를 대응시키며 사용자 승인 단발 여자아이에 화면 오른쪽 노란 막대 머리핀 하나를 추가했다. 내장 image_gen을 사용했다. 원본은 덮어쓰지 않는다.

- 고정 참조: 머리핀 여자아이 기본 그림 girl.png.
- 직접 부모: 각 감정의 기존 남학생 그림.
- 공통 프롬프트: 여자아이의 단발·머리핀 하나·크림 티셔츠·주황 반바지·양말·운동화·수채화 질감은 고정한다. 기존 감정 그림의 표정·몸짓·셔츠 감정 친구·동작 표시를 대응시킨다. 전신과 투명 배경을 유지하고 마음 자리 중심은 캔버스 (49.6%,58.1%)에 둔다.
- 결과: public/img/emotion/girl.png와 girl-{joy,sad,angry,tired,excited,anxious,meh,sick}.png.
- 검수: 9장의 머리핀 개수·방향, 의상, 감정별 몸짓과 색, 배경 투명도, 전체 그림의 잘림을 확인한다. 검수 화면은 감정캐릭터-미리보기.html이다.

## 화면과 저장

마음 일기 그림 위 남학생/여학생 단추로 선택한다. 선택 즉시 학생의 emotionAvatar에 저장하며 날짜 변경·새로고침 뒤에도 유지한다. 옷입히기 outfitAvatar와 독립적이다. 기존 학생은 기본 남학생으로 표시하며 사용자가 바꾸기 전 임의의 저장값을 만들지 않는다. 감정 내용과 선택한 캐릭터는 별도 자료다. 선택 실패 시 기존 그림을 유지하고 안내한다.

저장 형식과 IndexedDB 버전은 8. 이전 학급 자료는 그대로 유지하며 선택 필드가 없으면 기본값으로 표시한다. 백업은 학생별 선택을 포함한다. 서버 전송은 없다. 기존 CSP 변경은 필요하지 않다.
